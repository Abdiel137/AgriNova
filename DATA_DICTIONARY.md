# Data dictionary — demonstration dataset

All rows in this file are synthetic demonstration records, not official NISR statistics.

- `province`: illustrative province label
- `district`: illustrative district label
- `season`: illustrative season category
- `crop`: illustrative crop label
- `cultivated_area_ha`: synthetic cultivated area in hectares
- `production_tonnes`: synthetic production in tonnes
- `data_status`: label identifying each record as synthetic demo data
